## Featured project

### [VAILS](link-to-repo) — Voice Agent for Independent Living Support

A voice assistant that helps older adults live independently: it reminds
them about medication, checks in on how they're doing, and lets them just
talk instead of navigating an app. Family members and doctors get a
dashboard to stay in the loop.

My undergraduate thesis. Presented at BCI 2026 and published in the
Springer conference proceedings.

**Built with:** Python · FastAPI · Streamlit · SQLAlchemy · Gemini Live API · scikit-learn
